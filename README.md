# Skyland and Atlantis Adventure Games

## Overview
"Skyland" and "Atlantis" are two level adventure games developed using Python's Tkinter library. The games challenge players to navigate through a fantasy world, avoiding obstacles and collecting trophies to score points. The first level, "Skyland", is set in a whimsical land above the clouds, while the second level, "Atlantis", takes players underwater in an enchanted oceanic world.

## Requirements
- Python 3.x
- Tkinter library (usually comes with Python installation)

## Setup
1. Ensure Python and Tkinter are installed on your system.
2. Download the game scripts for Skyland and Atlantis.
3. Run the scripts individually:
   ```bash
   python skyland.py
   ```
   ```bash
   python atlantis.py
   ```

## How to Play

### Controls
- **Arrow Keys**: Move the avatar (Left, Right, Up, Down)
- **Space**: Pause the game
- **X**: Restart the game

### Objectives
- Navigate through the game environment without colliding with obstacles.
- Collect trophies to increase your score.
- Avoid enemies (spiders in Skyland, sharks in Atlantis) to survive.

### Scoring
- Each trophy collected increases your score.
- The game tracks the time taken to collect all trophies.

### Game Over Conditions
- Colliding with an enemy results in a game over.
- A prompt to restart the game appears after a game over.

## Features
### Skyland
- Dynamic obstacles and moving platforms.
- Enemies that follow simple AI patterns to challenge the player.
- Scenic backgrounds and immersive game elements tailored for a sky-themed adventure.

### Atlantis
- Underwater-themed gameplay with aquatic obstacles and enemies.
- Enhanced AI movements for sharks providing a challenging experience.
- Visually appealing underwater setting with animated obstacles and collectibles.
